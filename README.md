# StudentHub Portal

A full-stack, responsive web application for managing student profiles, event registrations, and role-based access control (RBAC).

---

## 📌 Project Overview
- **Student Management:** Full CRUD operations for student profiles.
- **Role-Based Access Control (RBAC):** Admin and Student roles with protected session handling.
- **Event System:** Dynamic listing and event registration.
- **RESTful Endpoints:** Fetch API integration for asynchronous updates without full page reloads.
- **Database Persistence:** MySQL database integration using PHP PDO.

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API / Async-Await), Bootstrap
- **Backend:** PHP (PDO)
- **Database:** MySQL
- **Local Server:** XAMPP (Apache & MySQL)
